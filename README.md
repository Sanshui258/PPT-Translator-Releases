# PPT Translator — 发行版 / Downloads

PPT/PDF 多语言 AI 翻译排版工具（Windows GUI / CLI）。通过 OpenAI 兼容接口调用大模型，支持混合模式（可编辑文本优先）与纯视觉模式（图片页面 / PDF 扫描识别），译文以黑体 + 金色高亮回填到原文附近位置，并内置 AI 前后校对。

## v1.2.0 更新（10 月版）—— 自 v1.1.1 以来的全部变化

### 1. 表格翻译（本月重点）

- **表格不再被整表跳过**：以前过滤规则拿整段文字去匹配单行规则，表格第一格只要像代码或公式（如 `x=1`），
  整张表就会被判成“无需翻译”一起丢掉。现在表格按「一格一条」提取、逐格判断，只有真正的数字 / 序号才跳过。
- **译文就地写回原表格单元格**：混合 / 文本模式下不再给单元格生成浮动文本框，而是把译文写回原单元格
  ——边框、底纹、合并格、字号样式完全不变，输出就是「一张和原来一模一样的表」，只是文字换成了目标语言。
- 数字、序号等不需要翻译的格子保持原样；被替换掉的原文写入该页备注，随时可查。
- 表格单元格和其它条目一样参与 AI 前后校对。

### 2. 排版

- **两阶段背景估计**：先估计并扣除背景（纯白、渐变、大色块都不再干扰），再在其上定位文字 / 墨迹活动区，
  空白块判断明显更准，译文更容易落在原文附近的空位。
- **候选顺序**改为「原文左右优先、其次上下」，并用**坐标范数**在最近的几个空白块里选一个互不遮盖的位置。
- **译文框宽度贴合文字**：以前会继承原框的整页宽度，框被拉得很长、候选位全部出界；现在按内容自适应。
- **阅读顺序排版**：元素按「从上到下、从左到右」依次排，不再堆在左下角 / 页面底部。
- **排版精细度可选**：1/6 粗略 · 1/8 标准 · **1/10 精细（默认）** · 1/12 极细（`LAYOUT_FINE_DIV`）。
- **框宽策略可配置**：上限 0.60 页宽、兜底下限 0.25、放不下时按 0.6 倍收窄重试
  （`LAYOUT_BOX_MAX_RATIO` / `LAYOUT_BOX_FLOOR_RATIO` / `LAYOUT_BOX_NARROW_RATIO`）。
- **修复**：此前整个文件所有页面共用一个“占用区”，每页候选都会撞到别页的原框，译文只能堆到页面底部；
  现在按页分别计算。

### 3. 字体与样式

- 新增**字体 / 样式菜单**：字体、字号、文字颜色、高亮色，混合、纯视觉、原地替换三种模式通用。
- **默认字体按目标语言自动选择**：目标英语 → 黑体 SimHei；目标中文 → 宋体 SimSun；
  目标韩语 → 맑은 고딕 Malgun Gothic；默认字号统一 12pt。
- 新增**字号策略**：`fixed`（统一字号，默认）/ `ratio`（原字号 × 7/16，并以配置字号保底）。
- **代码条目只翻译注释**：代码（关键字、变量名、路径、命令、符号、缩进、数字）逐字符原样保留，
  请求时带 `code` 标记提示模型。

### 4. 接口兼容

- 新增 **Anthropic Claude（Messages API）**：`x-api-key` + `anthropic-version` 鉴权头与 `/v1/messages`
  端点，与 OpenAI 方言自动识别（`AI_API_DIALECT` 可强制指定）。
- 新增 **OpenAI 官方 API** 规则（`/v1/chat/completions`，404 时回退 `/responses`）。
- **服务商规则扩展到 8 条**：Mindlogic（学校网关）/ DeepSeek / 智谱 GLM / 阿里千问百炼 / Kimi（Moonshot）/
  OpenAI / Anthropic / 万能兜底；按 Base URL 自动识别并补全规范路径（例如自动补 `/v1/gateway`）。
- **自动获取模型列表、测试连接**；按服务商给出针对性报错建议（401 / 403 / 404 / 429 等）。
- **修复**：混合模式不再被 `.env` 的 `VISION_MODE` 强制成视觉模式（此前选“混合”实际会跑纯视觉）。

### 5. 安装包与发行

- 新增 **Windows 安装程序**（`PPT_Translator_Setup_v1.2.0.exe`）：免管理员、按用户安装到
  `%LOCALAPPDATA%\Programs\PPT Translator`，自动创建开始菜单 / 桌面快捷方式，自带卸载程序。
- **升级不覆盖数据**：`.env`（API Key / 设置）、`cache/`（译文记忆）、`reports/`（含历史记录）、
  `logs/`、`input/`、`output/`、`prompts/` 全部原样保留。
- **从免安装压缩包迁移**：安装向导「继承旧版本配置」一步，选择旧目录即可继承 API Key、译文缓存与历史记录。
- 免安装 ZIP 继续提供；两种装法都不内置任何 Key（`.env` 为空白模板）。

### 6. 界面与可用性

- **界面现代化**：Windows 11 风格（Sun Valley）主题，可切换 跟随系统 / 浅色 / 深色（`GUI_THEME`）。
- **历史记录窗口**：回看每次翻译任务（时间 / 文件 / 结果 / 模式 / 输出路径，可打开输出目录、导出 CSV、删除），
  以及译文记忆（原文 / 译文 / 模型 / 时间，可搜索、查看、导出、删除、清空）；默认保留最近 200 次（`HISTORY_KEEP`）。
- **输出重名检测**：翻译开始前检查同名文件，弹窗选择 覆盖 / 重命名（加序号）/ 取消。
- **输入自动归档**：翻译成功后把原文件移入 `输入目录/translated/`，下次启动不再重复读取（可关闭）。
- 主界面新增「打开输出目录」按钮；新增界面文字全部做了中 / 英 / 韩三语适配。

### 7. 稳定性与修复

- 译文缓存文件损坏时自动备份重建并提示“本次将重新翻译”，不再让整个任务失败。
- 安装向导「继承旧版本配置」页：路径框与勾选框联动，**勾选后才能填写 / 浏览**旧目录。
- 四份使用指南与 README 全部同步更新到本版。

## 快速开始 / Quick Start

1. 安装版：双击 `PPT_Translator_Setup_v1.2.0.exe`，一路「下一步」；免安装版：解压后双击 `PPT_Translator.exe`。
2. 在界面中设置输入 / 输出目录，可直接把 PPTX / PPT / PDF 文件拖进窗口。
3. 填写 OpenAI 兼容的 Base URL 与 API Key（支持自动获取模型列表与测试连接）。
4. 选择处理模式：混合（文本优先，缺文本自动转视觉）或 纯视觉。
5. 点击开始，全部完成后自动打开输出目录。

- 环境要求：Windows 10/11 64 位；`.ppt` 转换与视觉渲染需要本机安装 Microsoft PowerPoint。
- 程序不会修改源文件，结果输出到所选输出目录。
