# PPT Translator — 发行版 / Downloads

PPT/PDF 多语言 AI 翻译排版工具（Windows GUI / CLI）。通过 OpenAI 兼容接口调用大模型，支持混合模式（可编辑文本优先）与纯视觉模式（图片页面 / PDF 扫描识别），译文以黑体 + 金色高亮回填到原文附近位置，并内置 AI 前后校对。

**v1.5.0 起新增 Word / 한글 文档翻译**：`.docx` / `.doc` / `.hwpx` / `.hwp` 原位替换、不排版，输出格式与输入一致。

## v1.5.0 更新（10 月月中版）—— 自 v1.2.0 以来的全部变化

### 1. Word / 한글 文档翻译（本月重点）

- **新增文档链路，与 PPT 链路并列**：`.docx`（Word）与 `.hwpx`（한글）用纯 Python 直接改写，**不需要安装 Office 或 한글**；
  `.doc` / `.hwp` 由本机 Word / 한글 先换壳，改完再换回原格式。
- **输出格式与输入一致**：`.doc` 进 `.doc` 出、`.hwp` 进 `.hwp` 出，不会被强转成 PPTX。
  万一最后一步换回失败，会退回中间格式（`.docx` / `.hwpx`）并在报告里标 warning，不会假装成功。
- **原位替换，完全不做排版**：译文直接写回原段落，段落位置、编号、缩进、样式都留在原地；
  表格样式、底纹、合并格、图片、页眉页脚、公式一概不动。界面上「混合 / 纯视觉」的切换对文档不生效。
- **表格按「一格一条」处理**，只有真正的数字 / 序号才跳过。
- **文档插图可选识别**：默认每张插图调一次多模态，译文以新段落插在图片后面；可在界面关掉（`DOC_IMAGE_VISION=0`）。
- **文档字号独立策略**：默认**保留原字号**（`DOC_FONT_SIZE_MODE=keep`），需要统一时选「统一字号」或「原字号×7/16」。
- **离线自检**：写完会重新打开成品，核对段落数、图片数与译文是否真的落盘，结果写进 `reports/`。

### 2. 全新界面（PySide6）

- 界面改用 **PySide6 + MaterialDark 扁平主题**：左右分栏、浅色 / 深色双主题，箭头图标全部由 `QPainter` 运行时绘制，发行包不含位图资源。
- 拖放文件、进度与状态、模型列表 / 测试连接、历史记录、使用说明等入口全部保留并重排；文档选项（字号策略、插图识别）独立成区。
- 没装 PySide6 时自动回退旧版 Tkinter 界面，不会打不开。

### 3. 速度与稳定性

- **并发调度**：页级 / 批次级并行处理，保序执行、最后按原顺序串行拼回，视觉模式与大文件明显更快。
- **修复 HTTP 413**：图片超过网关体积上限时自动缩放并重编码为 JPEG 再发送（手机照片、大截图常见）。
- **修复 한글 插图插入把整张表格克隆出来的问题**（曾出现 1 张表变 12 张、50 段变 597 段）。
- 补齐停止 / 内存释放、大文件拆分失败、上下文超限等防错路径。

### 4. 表格与排版（自 v1.2.0 起累积）

- 表格按「一格一条」翻译，译文就地写回原单元格，边框 / 底纹 / 合并格不变。
- 两阶段背景估计 + 坐标范数选位 + 阅读顺序排版：译文不再堆在页面底部，文本框宽度贴合译文内容。

### 5. 界面与发行（自 v1.2.0 起累积）

- 安装包升级不覆盖 `.env` / `cache/` / `reports/` / `logs/` / `input/` / `output/` / `prompts/`；
  从免安装压缩包迁移时可继承旧目录的 Key、缓存与历史记录。
- 历史记录窗口：任务记录（时间 / 文件 / 结果 / 模式 / 输出路径）+ 译文记忆（搜索 / 导出 CSV / 删除）。
- 翻译开始前做输出重名检测（覆盖 / 重命名 / 取消），完成后把原文件归档到 `translated/`。
- 界面 中 / EN / KO 三语，含进度、状态与报错。

## 快速开始 / Quick Start

1. 安装版：双击 `PPT_Translator_Setup_v1.5.0.exe`，一路「下一步」；免安装版：解压后双击 `PPT_Translator.exe`。
2. 在界面中设置输入 / 输出目录，可直接把 PPTX / PPT / PDF / Word / 한글 文件拖进窗口。
3. 填写 OpenAI 兼容的 Base URL 与 API Key（支持自动获取模型列表与测试连接）。
4. 选择处理模式：混合（文本优先，缺文本自动转视觉）或 纯视觉；文档自动走原位替换链路。
5. 点击开始，全部完成后自动打开输出目录。

- 环境要求：Windows 10/11 64 位；`.ppt` 转换与视觉渲染需要本机安装 Microsoft PowerPoint。
- `.docx` / `.hwpx` 文档不需要任何办公软件；`.doc` / `.hwp` 需要本机安装 Word / 한글。
- 程序不会修改源文件，结果输出到所选输出目录。
