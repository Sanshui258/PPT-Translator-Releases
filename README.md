## 使用说明

1. 解压 zip，双击 `PPT_Translator.exe`。
2. 在界面中设置输入 / 输出目录。
3. 填写 OpenAI 兼容的接口地址与 API Key（默认阿里云百炼千问 / DashScope），选择模型（可自动获取）。
4. 选择处理模式：混合（有可编辑文本走文本翻译）/ 纯视觉（图片页面 / PDF 扫描识别），点击开始。

- 环境要求：Windows 10/11 64 位；`.ppt` 转换与视觉渲染需要本机安装 Microsoft PowerPoint。
- 程序不会修改源文件，结果输出到你所选的输出目录。
